# 업무 기한 계산기 (Deadline Calculator) 📅⚡

> 달력 기준 마감일과 주말·공휴일을 제외한 실제 근무일(영업일) 마감일을 실시간으로 비교·계산하고, 사내 메신저나 이메일에 바로 공유할 수 있는 실무용 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **시작일 및 기간 간편 설정**
   - 시작일 날짜 선택기 (`오늘` 빠른 설정 버튼 제공)
   - 숫자 직접 입력 및 자주 쓰는 빠른 기간 프리셋 버튼 (`+3일`, `+5일`, `+7일`, `+10일`, `+14일`, `+30일`)
   - **초일 산입 / 초일 불산입 옵션 토글**: 실무 프로젝트 기준(시작일 당일 포함)과 민법 기준(시작일 익일부터 카운트) 자유 선택

2. **달력 기준 vs 근무일 기준 마감일 실시간 비교**
   - **달력 기준 마감일**: 주말·공휴일을 포함한 단순 일수 계산
   - **근무일 기준 마감일**: 주말(토/일) 및 법정·맞춤 공휴일을 제외한 실제 영업일 마감일 계산 및 제외된 일수(주말 X일, 공휴일 Y일) 요약
   - **건너뛴 날짜 태그 리스트**: 업무 기간 동안 실제로 건너뛴 주말 및 공휴일(예: `🔴 10/3(토) 개천절`, `🟣 11/4(수) 창립기념일`, `10/31(토)`)을 시각적 배지로 표시

3. **오늘 기준 실시간 D-day 배지**
   - 마감일 결과 카드 상단에 오늘 기준 잔여일수 자동 계산
   - `D-12` (잔여), `D-Day` (당일 펄스 애니메이션), `D+3 (기한 경과)`

4. **공휴일 자동 제외 & 맞춤 휴일 관리 (`localStorage`)**
   - **대한민국 법정공휴일 및 대체공휴일(2025~2028년)** 기본 내장
   - `[공휴일도 제외하기]` 토글 스위치로 공휴일 산입 여부 제어
   - 하단 아코디언 메뉴를 통해 회사 창립기념일, 개인 연차, 하계휴가 등 사용자 맞춤 휴일을 직접 추가/삭제 가능하며 브라우저 `localStorage`에 자동 영구 저장

5. **보고용 원클릭 복사**
   - `[📋 보고용 텍스트 복사]` 버튼 클릭 시 슬랙, 팀즈, 카카오톡, 잔디, 이메일에 최적화된 형식으로 클립보드 복사
   - 복사 형식:
     `[업무 기한 안내] 시작일: 2026-10-30 / 소요 기간: 10일 / 달력 기준 마감: 2026-11-08(일, D-9) / 근무일 기준 마감: 2026-11-12(목, D-13)`
   - 플로팅 토스트 알림 자동 출력

## 🚀 로컬 실행 방법

외부 빌드 도구(npm, vite 등)나 의존성 설치 없이 웹 브라우저에서 즉시 실행할 수 있습니다.

### 방법 1. 파일 직접 열기
- 파일 탐색기에서 `deadline-calc/index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등의 브라우저로 열기

### 방법 2. 로컬 웹 서버 사용 (선택)
VS Code의 `Live Server` 확장 또는 npx 명령어를 사용할 수 있습니다:
```bash
# Node.js가 설치되어 있는 경우
npx serve deadline-calc
```

## 🌐 GitHub 업로드 및 Vercel 배포 가이드

### 1. GitHub 저장소에 업로드
```bash
# Git 초기화 및 커밋
git init
git add .
git commit -m "feat: 업무 기한 계산기 웹앱 초기 구현 (GitHub + Vercel 배포용)"

# 원격 저장소 연결 및 푸시
git branch -M main
git remote add origin https://github.com/사용자이름/저장소이름.git
git push -u origin main
```

### 2. Vercel 배포
1. [Vercel](https://vercel.com/)에 로그인 후 **[Add New...]** -> **[Project]** 클릭
2. 방금 올린 GitHub 저장소를 선택하고 **[Import]** 클릭
3. **배포 설정(Configure Project)**:
   - **Framework Preset**: `Other` 선택
   - **Root Directory**: `./deadline-calc` 로 지정하거나, 루트 디렉토리(`.`) 그대로 두셔도 내장된 `vercel.json`에 의해 자동으로 올바르게 서비스됩니다.
4. **[Deploy]** 버튼 클릭
5. 몇 초 만에 무료 HTTPS 배포 주소(예: `https://your-project.vercel.app`)가 생성됩니다.
